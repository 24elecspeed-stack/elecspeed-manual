연결 상태

현재 연결된 네이버 블로그·카페·티스토리 또는 Google Blogger 글쓰기 페이지를 확인하는 중입니다.

블로그 ID를 입력해두면, 매번 직접 글쓰기 화면을 열지 않고 아래 버튼으로 바로 이동 후 연결할 수 있습니다.

Threads 게시물 준비

로그인한 Threads 홈·프로필에서 현재 탭을 연결하세요. 글만 입력하거나 이미지 1~10장을 함께 넣을 수 있습니다. 게시 버튼은 직접 누릅니다.

긴 글은 ‘스레드에 추가’로 연결합니다. 각 글은 500자 이하이며, 이미지는 첫 번째 글에 첨부합니다. 구성 변경 후 글을 다시 생성하세요.

카드뉴스는 1~10장으로 구성하며 첫 번째 글에 첨부합니다. 4장 이상은 표지 → 핵심 내용 → 예시 → 마무리 순서이며, 1~3장은 내용을 합칩니다. 장별 문구를 수정할 수 있으며, 생성 후 이미지 속 오탈자를 확인하세요.

0 / 500자

글당 500자, 최대 10개 연결·이미지 최대 10장을 지원합니다. 글·프롬프트는 저장되며 이미지는 패널을 닫기 전에 다운로드하세요.

Instagram 게시물 준비

선택한 수의 이미지와 캡션을 한 게시물에 입력한 뒤 공유 직전에 멈춥니다. Instagram에 로그인하고 현재 탭을 연결하세요. 이미 작성 중인 게시물은 덮어쓰지 않습니다.

4장 이상 권장: 표지 → 핵심 내용 → 예시 → 마무리. 1~3장은 내용을 합쳐 구성합니다. 생성 전 장별 문구와 프롬프트를 수정할 수 있습니다. AI가 이미지 안에 글자를 그리므로 생성 후 오탈자를 확인하세요.

캡션 생성 시 선택한 개수만큼 서로 다른 이미지 프롬프트도 함께 만듭니다.

모든 이미지별 프롬프트에 반영합니다. 비워두면 주제에 맞게 정합니다. 스타일을 바꾼 뒤에는 캡션을 다시 생성하세요. 기존 이미지에는 자동 반영되지 않습니다.

0 / 2,200자

② 장별 구성 · 이미지 프롬프트

JPEG·PNG·WebP, 8MB 이하. 일반 이미지·카드뉴스 생성과 이미지별 재생성 시 현재 템플릿을 AI에 첨부합니다. 게시 이미지로 추가되지는 않습니다. 템플릿 파일은 패널을 닫으면 다시 등록해야 합니다.

기존 이미지 뒤에 추가됩니다(총 10장까지). 수동 추가는 AI 생성 없이 가능하며, 비율이 맞지 않으면 사진을 자르지 않고 흰 여백을 넣습니다. 기존 한 장을 바꾸려면 아래 ‘파일 교체’를 사용하세요.

③ 생성 이미지 수정 · 관리

수동 이미지는 비율 제한 없이 추가할 수 있습니다. 게시 전 AI 레이블 등 설정도 직접 확인하세요.

초안 입력

주제와 조건을 직접 입력하는 방식, 기존 네이버 블로그 검색 결과를 참고하는 방식, 네이버 검색 결과를 참고하는 방식 중 하나를 고를 수 있습니다.

선택한 검색 결과의 상위 글 제목 패턴, 검색 의도, 자주 다루는 포인트를 참고해 새 초안을 만듭니다.

500~10,000자 · 목표 글자 수의 ±10% 범위로 작성합니다.

글 유형은 내용의 전개 방식을, 서식 프리셋은 강조 블록과 시각 구성을 결정합니다.

소제목, 강조 상자와 링크에 적용됩니다.

지원되는 AI 화면에서는 임시채팅을 우선 사용하고, 찾지 못하면 일반 새 채팅으로 이어집니다.

초안 작성 전에 선택하면 해당 개수의 이미지 프롬프트를 함께 만듭니다. 초안 작성 후 개수를 늘리면 부족한 프롬프트는 자동으로 보충합니다.
