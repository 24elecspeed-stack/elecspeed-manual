**REST와 실제 HTML을 구분할 것.** 297개는 API 불일치 수이며, 실제 페이지 297개가 로고를 출력한다는 의미가 아니다.

HTML 표본 ID 3169, 3018, 2579, 1145, 1126은 모두 og:image 주소가 각 글 대표사진이었다. 최신 글 3169는 1200×630, image/jpeg로 정상. 나머지 네 표본은 JPEG 사진 URL을 출력하면서 크기·형식이 예전 520×520, image/png로 남았다. URL만 교체하는 서버 필터 가능성이 있으나 관리자 코드를 확인하지 못해 원인 구현은 미확정이다.

robots.txt는 업로드 경로를 차단하지 않는다. 확인한 HTML은 max-image-preview:large를 출력한다. 크롤링·색인 전체 정상 여부를 보증하는 검사는 아니다.
