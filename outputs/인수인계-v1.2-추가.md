# 인수인계 추가 사항 · v1.2

이 문서는 기존 인수인계서보다 우선하는 변경 사항입니다.

## 사용자 의도 정정

사용자는 제목·본문 전체 수동 입력을 원하지 않았다. 원본 APK처럼 **카테고리 설정 → ChatGPT 요청문 자동 생성·복사·앱 열기 → 답변 가져오기**를 원하며, 최종 워드프레스 게시글만 tot.py 폼으로 적용하길 원한다.

## 최신 결과

- `elecspeed-chatgpt.apk`: package `com.elecspeed.manual`, versionName 1.2, versionCode 3, 기존 개발용 키로 서명.
- `elecspeed-chatgpt-source.zip`: 최신 소스·배너·매니페스트·빌드 스크립트·테스트. 서명 키는 미포함.
- `ChatGPT-카테고리-사용방법.md`: 최신 사용 흐름.

## 참고한 원본 구현

`C:/Users/manowar/Desktop/ElectricBlogClipboard_AndroidProject/ElectricBlogClipboard/app/src/main/java/com/electric/blogclipboard/`에서 MainActivity.kt, BlogTextGenerator.kt, Category.kt, CategoryStore.kt, CategoryManagerActivity.kt를 읽었다. 첨부 APK의 기능과 부합하는 소스가 발견되었으나 첨부 APK와 해당 소스의 빌드 일치 여부를 해시로 확정한 것은 아니다.

원본의 ChatGPT 열기·클립보드 가져오기 흐름, 카테고리 필드, 기본 카테고리 3개의 내용을 반영했다. 글 생성용 OpenAI API 호출은 없다.

## 변경한 구조

- MainActivity.java: 카테고리 선택, 지역·작업 종류, 선택 메모, ChatGPT 열기/가져오기 중심으로 작성 화면 재구성. 직접 작성 필드는 확인·수정 영역으로 접었다.
- ArticleCodec.java: Android 의존성 없는 요청문 생성과 답변 파싱. CRLF/CR, 코드블록, 마크다운 표식, 원본 구간 표식, Q&A 위치, 표식 없는 글을 처리한다.
- WritingCategory.java: 원본 카테고리 설정 모델과 3개 기본값, 조사 요청문 생성.
- CategorySettings.java: 카테고리 추가·수정·삭제·로컬 저장. 데이터는 writer_categories SharedPreferences에 저장한다.
- 매니페스트: ChatGPT 패키지 조회를 위한 queries 항목 추가.
- draft SharedPreferences: notes, category, history, variation, lastPrompt 추가. 비밀번호 저장 없음.
- 기본 카테고리를 변경할 때 사이트 작업 유형의 초기 선택도 변경한다. ChatGPT 카테고리와 워드프레스 taxonomy는 별개이며 taxonomy 최종 선택을 확인할 수 있다.

## 빌드

`work/android/build.ps1`을 실행한다. 프로젝트 경로 기준 출력은 `outputs/elecspeed-chatgpt.apk`다. JavaBin, BuildTools, PlatformJar, OutputApk 매개변수로 환경을 변경할 수 있다. 기존 signing.jks가 필요하다.

이전 javac는 클래스 생성 뒤 zipfs를 닫을 때 권한 예외가 났다. 새 CompileAndroid.java는 표준 JavaCompiler API로 실제 컴파일 성공 값을 확인하고 파일 관리자는 프로세스 종료까지 유지한다. 새 스크립트는 매번 별도 build-GUID 폴더를 만들어 이전 클래스가 섞이지 않게 하고 도구 실패 시 중단한다. 컴파일 성공 및 최종 APK 서명 검증을 확인했다.
