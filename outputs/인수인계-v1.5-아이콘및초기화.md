# elecspeed 앱 v1.5 추가 (2026-09-13)

v1.4 마이그레이션 다음에 이어지는 내용입니다.

## 1. 앱 아이콘 적용

사용자가 채팅에 올린 `24시 전기수리` 캐릭터 로고 이미지로 앱 아이콘을 만들었습니다.

- 원본: `D:\배경사진\ChatGPT Image 2026년 8월 19일 오후 12_37_52.png` (채팅에 올린 것과 동일 확인)
- 이 원본은 큰 제목·태그라인·배지 텍스트까지 포함한 배너라서, 작은 런처 아이콘 크기(48~192px)로
  그대로 줄이면 글자가 뭉개집니다. 그래서 같은 캐릭터의 원형 엠블럼 부분만 있는
  `D:\배경사진\24elecspeed_로고_520x520.png`에서 하단 텍스트(상호명·전화번호)를 잘라내고
  정사각형(520x520)으로 다시 만든 뒤 아이콘 소스로 썼습니다.
  - 작업 파일: `work/android/icon-src/logo-full.png`(원본 복사본), `icon-src/icon-square.png`(최종 정사각형)
- `res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`(+`ic_launcher_round.png`)를
  48/72/96/144/192px로 생성.
- `AndroidManifest.xml`의 `<application>`에 `android:icon="@mipmap/ic_launcher"`,
  `android:roundIcon="@mipmap/ic_launcher_round"` 추가.
- `build.ps1`의 aapt package 명령에 `-S "$PSScriptRoot/res"`를 추가해야 mipmap이 실제로
  패키징됩니다(이전에는 `-S res`가 없어서 res 폴더 자체가 무시됐습니다 — v1.3 문서에 이미
  적혀 있던 제약).
- adaptive icon(안드로이드 8 이상 원형/사각 마스크에 맞춰 배경/전경을 분리하는 최신 방식)은
  만들지 않았습니다. 지금은 옛날 방식의 고정 PNG 아이콘이라 일부 런처에서 자체적으로
  둥글게/네모나게 잘라서 보여줄 수 있습니다. 필요하면 나중에 `mipmap-anydpi-v26/ic_launcher.xml`
  (배경+전경 레이어)로 바꿔주세요.
- `aapt dump badging`으로 `application-icon-*` 항목이 mipmap PNG를 가리키는 것,
  APK 안에 `res/mipmap-*/ic_launcher*.png`가 실제로 들어간 것을 확인했습니다.
  **에뮬레이터/실기기에 설치해 런처 화면 아이콘 모양은 아직 눈으로 확인 못 했습니다.**

## 2. "글 초기화" 버튼 추가

편집 화면 맨 위 헤더에 [글 초기화] · [로그아웃] 버튼을 나란히 배치했습니다
(`MainActivity.showEditor()`). 예전에는 로그아웃 버튼만 있었습니다.

- 눌러도 바로 지우지 않고 "지역·작성 중인 글·현장 메모를 모두 지울까요? 로그인과 카테고리는
  유지됩니다."라는 확인창을 먼저 띄웁니다.
- 확인하면 `clearArticle()`이 실행됩니다: 구/시, 동, 현장 메모, 제목·본문·증상·원인·작업내용을
  모두 비우고, "가져온 글 확인·수정" 펼침 영역을 다시 접고, 4번 카드 요약을
  "가져온 글이 없습니다."로 되돌립니다. SharedPreferences `draft`의 해당 항목(`f1`~`f7`,
  `notes`)도 같이 지웁니다.
- **지우지 않는 것**: 로그인 아이디(`user`)·비밀번호, 선택한 카테고리, 작업 종류 선택,
  ChatGPT 중복 방지용 최근 제목 기록(`history`)과 요청문 변주 카운터(`variation`). 이 값들은
  다음 글 작성에도 계속 필요하다고 판단해 남겨뒀습니다.
- `busy`(등록 요청 진행 중)일 때는 "등록이 끝난 뒤 초기화해 주세요."만 띄우고 지우지 않습니다.

  버튼 추가는 기능 동작을 안 바꿔서 버전은 안 올렸습니다).

  어색한지)는 설치해서 눈으로 봐야 합니다.
