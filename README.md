# elecspeed-manual

전기수리 사례·정보성 글 요청문을 ChatGPT에 전달하고, 완성 답변을 Android 앱에서 가져와 WordPress에 등록하는 프로젝트입니다.

**먼저 [최신 인수인계서](docs/인수인계-2026-09-20.md)를 읽으세요.**

현재 Git 저장소 `work/android`는 v1.2이며, 이 대화의 v1.12 소스는 별도 로컬 작업 폴더에 있습니다. 원격 `chatgpt-categories-backup` 브랜치에는 v1.13·v1.14 표기의 후속 작업도 있습니다. 최신 인수인계서에 경로와 차이, 빌드 방법, 검증 범위, 미완료 작업을 기록했습니다. 이 문서 추가 커밋은 최신 소스 동기화를 포함하지 않습니다.

- 대상 사이트: https://24elecspeed.com
- 대상 패키지: `com.elecspeed.manual`
- 글쓰기 연결: ChatGPT
- 실기기·실제 AI 응답·서버 등록 종합 검증: 미완료

기존 인수인계 자료는 이력 참고용입니다. ElectricBlogClipboard(네이버 앱)와 혼동하지 마세요.
